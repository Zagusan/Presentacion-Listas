¿Qué es una lista?

¿Qué es una lista?

En Python, una lista es un contenedor ordenado y mutable. Esto significa que:

  • Puede tener muchas variables adentro
  • Se le da importancia al orden de los elementos
  • Se puede modificar después de ser creada

¿Cómo usar las listas?

¿Cómo usar las listas?

Declaración

Lista vacía


										miLista = []
									

										miLista = list()

Lista con elementos


										miLista = [1, 2, 3, 4, 5]
									

										miLista = ["¡Hola", "mundo!"]
									

										miLista = [1, "texto", 2, True]

Usos (1)

Acceder a un elemento específico


										miLista = [1, "texto", 2, True]
										print(miLista[0]) # Imprime 1
										print(miLista[1]) # Imprime texto
										print(miLista[3]) # Imprime True
										print(miLista[-1]) # Imprime True

Iterar sobre los elementos


										for elemento in miLista:
											print(elemento)

¿Cómo usar las listas?

Usos (2)

Almacenar muchos datos


										for _ in range(5):
											numero = input("Escribe un número: ")
											miLista.append(numero)

Ordenar números


										miLista = [5, 3, 7, 4]
										miLista.sort()
										print(miLista) # Imprime [3, 4, 5, 7]

Métodos

  • miLista.append(x): Añade un elemento al final de la lista
  • miLista.pop(i): Elimina el elemento ubicado en i
  • miLista.insert(i, x): Coloca un elemento en i y desplaza los demás hacia la derecha
  • miLista.remove(x): Elimina el primer valor que sea igual que x
